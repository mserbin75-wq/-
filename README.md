# -# ПроСвет 🎓

ИИ-помощник для школы в Telegram. Помогает учителям, ученикам и родителям с учебными материалами — от тестов и планов уроков до объяснений тем и помощи с домашкой.

В основе — **GigaChat API** от Сбера, обёрнутый в Telegram-бота на **aiogram 3.x**.

---

## Возможности

### Для учителя
- **Создать тест** — 8–10 заданий (с выбором, кратким ответом, развёрнутым) с ключами и критериями оценивания. Три уровня сложности.
- **План урока** — цели, этапы (орг. момент → рефлексия → ДЗ), методы и формы работы, раздаточные материалы.
- **Раздаточные карточки** — 5–6 компактных карточек с заданием и образцом ответа, готовых к печати.
- **Проверить работу** — вставляешь текст работы ученика, бот оценивает, указывает ошибки и даёт рекомендации.
- **Мои материалы** — история созданных материалов.

### Для ученика
- **Объяснить тему** — простыми словами, как старший товарищ, с примерами из жизни и проверочными вопросами.
- **Мини-тест** — 5–7 коротких задач по последней теме с ответами.
- **Разбор ошибок** — подробно разбирает, в чём ошибся, и даёт похожие задачи для закрепления.
- **Мои материалы** — история объяснений и тестов.

### Для родителя
- **Помощник ДЗ** — простое объяснение темы + 3–4 тренировочных задания с ответами.
- **Объяснить тему ребёнку** — доходчивое объяснение, чтобы родитель мог пересказать ребёнку.
- **Тренировочные задания** — 3–4 коротких задания с ответами для тренировки.

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/твой-репозиторий/prosvet-bot.git
cd prosvet-bot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Получение ключей

**Telegram Bot Token:**
1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Создай нового бота: `/newbot`
3. Скопируй токен

**GigaChat Credentials:**
1. Зайди на [developers.sber.ru](https://developers.sber.ru/)
2. Создай проект → получи **Authorization Key** (base64, длинная строка)
3. Скопируй его (не Client Secret, а именно Authorization Key)

### 4. Настройка

Открой `bot.py` в любом редакторе и вставь свои ключи:

```python
BOT_TOKEN = "токен_от_botfather"
GIGACHAT_CREDENTIALS = "credentials_от_gigachat"
```

### 5. Запуск

```bash
python bot.py
```

В консоли появится:

```
Бот ПроСвет запущен!
Start polling
Run polling for bot @твой_бот
```

## Деплой

### На VPS (24/7)

1. Подключись к серверу:
   ```bash
   ssh root@IP_АДРЕС
   ```
2. Установи Docker:
   ```bash
   apt update && apt install -y docker.io docker-compose
   ```
3. Загрузи файлы на сервер
4. Запусти:
   ```bash
   docker-compose up -d --build
   ```

### Локально (для разработки)

Просто держи `python bot.py` запущенным. Бот работает, пока включён компьютер и есть интернет.

## Как пользоваться

1. Открой бота в Telegram
2. Нажми `/start`
3. Выбери роль: **Учитель**, **Ученик** или **Родитель**
4. Используй кнопки меню для нужных задач
5. В любой момент — «Сменить роль», чтобы переключиться
